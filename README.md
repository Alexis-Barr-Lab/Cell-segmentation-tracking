This code implements background removal, Cellpose segmentation (Pachitariu, Marius, Michael Rariden, and Carsen Stringer. "Cellpose-SAM: superhuman generalization for cellular segmentation." bioRxiv (2025): 2025-04.), watershed refinement, GPU contour detection, displacement estimation, and Ultrack-based tracking (Bragantini, J., Theodoro, I., Zhao, X. et al. Ultrack: pushing the limits of cell tracking across biological scales. Nat Methods (2025). https://doi.org/10.1038/s41592-025-02778-0) for time-lapse microscopy. The notebook Notebook_CP_Ultrack.ipynb enables interactive testing of the segmentation and tracking while Notebook_CP_ultrack_batch.ipynb and Process_movie_multichannel.py are used for batch processing of movies.
